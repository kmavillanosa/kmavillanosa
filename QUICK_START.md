# 🚀 Quick Start: SEO & Portfolio Visibility

## Immediate Actions (5 minutes)

### 1. Generate Sitemap
```bash
cd app
npm run sitemap
```

### 2. Submit Sitemap to Google
1. Go to [Google Search Console](https://search.google.com/search-console)
2. Add your property: `https://kmavillanosa.github.io`
3. Submit sitemap: `https://kmavillanosa.github.io/kmavillanosa/sitemap.xml`
